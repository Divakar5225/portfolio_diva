# Divakar Guru – Engineering Portfolio

A modern, responsive engineering portfolio built using **React**, **TypeScript**, and **Vite**.

## 🚀 Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS (Coming Soon)
- Framer Motion (Coming Soon)

## 📌 Features

- Professional engineering portfolio
- Research showcase
- Project case studies
- Skills and experience
- Contact page
- Responsive design
- Dark/Light mode
- GitHub Pages deployment

## 🛠 Getting Started

Clone the repository:

```bash
git clone https://github.com/Divakar5225/portfolio_diva.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
